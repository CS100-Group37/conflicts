# Project Proposal

## About

We are Ben Raz[^1], Qirui Ma[^2], and Nathaniel Rios[^3]. Our proposed project is called `conflicts` and it aims to simplify time management.

## Problem Statement

Scheduling is one of the most difficult aspects of modern life. People are expected to remember when and where things are going to happen and they are also expected to be able to foresee any possible conflicts and avoid them beforehand.

Most people rely on physical or digital calendars, but their interfaces can often be annoying or tedious to use, especially physical calendars.

The goal of `conflicts` is to make this task easier by building a powerful and easy to use command-line interface that greatly simplifies the task of adding events and checking for conflicts by using a concise syntax and a focused interface.

## Core features

1) Ability to add events  
2) Ability to check a time slot and see if it conflicts with any events  
3) Ability to add recurring events  
4) Storage of events in a JSON file so they are not lost between sessions and can be moved off of the tool if desired.
